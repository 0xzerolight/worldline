Inside a tube

Ten wire cathodes stand one behind the other, front to back 1 6 2 7 5 0 4 9 8 3, behind a square anode mesh. Only the lit one glows; those in front of it catch a little of its light, those behind stay grey.

Everything here is drawn in code from the same digit paths the widget uses. Tap a cathode to light it.

On your desktop

Worldline is a widget for KDE Plasma 6. It sits on the desktop or in a panel, drifts to a new worldline every 20 to 60 minutes, shifts when you click it, and does nothing at all in between.

git clone https://github.com/0xzerolight/worldline
cd worldline && make install

Or download worldline.plasmoid and pick Get New Widgets… → Install Widget From Local File… in Add Widgets, or run

kpackagetool6 -t Plasma/Applet -i worldline.plasmoid

Then add Worldline from Add Widgets.
